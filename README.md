# AIGC 跨界视频编导个人网站

这是一个根据附件内容和 Neo-Brutalism 参考风格生成的响应式静态个人网站。

## 文件

- `index.html`：页面内容结构
- `styles.css`：新粗野主义视觉样式与响应式布局
- `script.js`：移动端导航、作品 Tab、微信号复制交互

## 可替换内容

- 将 `index.html` 中的 `your-email@domain.com` 替换为真实邮箱
- 将 `你的微信号` 替换为真实微信号
- 将“商业案例”和“AIGC 实验室”里的项目描述替换为真实作品
- 如有头像、二维码、视频或作品图，可替换当前代码生成的插画和预览卡
